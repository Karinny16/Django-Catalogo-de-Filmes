# Django--Catalogo-de-Filmes

Para executar o projeto, acesse o arquivo "catalogo" que é encontrado dentro da pasta "Anime" no seu cmder e escreva o seguinte comando "python -m venv venv
" para criar o ambiente virtual, para ativa-lo no Windows:venv\Scripts\activate ou no macOS/Linux:source venv/bin/activate.
Escreva o comando "python manage.py runserver" para executar o servidor local. Ao acessar,verá o catalogo dos animes cadastrados pelo Admin.
